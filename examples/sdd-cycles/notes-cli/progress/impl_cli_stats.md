# Implementación — cli_stats

Implementación completada con éxito.

## Trazabilidad
- R1 → `stats with one note prints metrics`, `stats with multiple notes computes averages and range`
- R2 → `stats with one note prints metrics`, `stats with multiple notes computes averages and range`
- R3 → `stats empty prints sin notas`
- R4 → `stats with one note prints metrics` (las notas no cambian al finalizar el comando)
- R5 → `stats rejects extra arguments`
